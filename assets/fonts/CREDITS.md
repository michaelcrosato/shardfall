# Fonts

The fonts the game draws its lines with in the AI Hub's languages (docs/LANGUAGES.md), made by
`scripts/fonts.py` from Noto fonts in google/fonts (pinned by SHA-256 there): each pinned to its
regular weight and cut down to the characters its languages use.

| File | From | Covers |
|---|---|---|
| NotoSans.ttf | Noto Sans | Latin (Vietnamese, Turkish, Hausa, Yoruba), Greek, Cyrillic |
| NotoSansArabic.ttf | Noto Sans Arabic | Arabic, Urdu |
| NotoSansDevanagari.ttf | Noto Sans Devanagari | Hindi |
| NotoSansBengali.ttf | Noto Sans Bengali | Bengali |
| NotoSansEthiopic.ttf | Noto Sans Ethiopic | Amharic |
| NotoSansSC.ttf | Noto Sans SC | Simplified Chinese (GB 2312 level 1) |
| NotoSansTC.ttf | Noto Sans TC | Traditional Chinese (Big5 level 1) |
| NotoSansJP.ttf | Noto Sans JP | Japanese (kana, JIS level 1 kanji) |
| NotoSansKR.ttf | Noto Sans KR | Korean (KS X 1001 Hangul) |
